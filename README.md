## Features
- Triple layer 3D printed case
- 128x32 OLED Display
- EC11 Rotary encoder for volume and scrolling through other shortcut layers 
- 6 keys
- Very cool swirly design – trust me, it looks awesome in person

## CAD Model
The CAD model is held together with 4 M3 screws and heatset inserts. It’s built in three layers: the bottom layer holds all the components, the middle layer keeps the switches in place, and the top layer is mainly there to look nice.

## BOM:
Here is a list of everything you would need to build the MultiPad

- 6x Cherry MX Switches
- 6x DSA Keycaps
- 4x M3x5x4 Heatset inserts
- 2X M3x12mm Bolts
- 1x 0.91" 128x32 OLED Display
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
- 1x Case (3 3D printed parts)
